# ScanDoc: Google Play store assets

Generated by `node scripts/branding/render.mjs`. Do not edit the images by hand.

- **Icon source:** `assets/launcher.icon/app_icon.png` (512×512). The script extracts the glyph from its
  cream background and rebuilds every icon (adaptive layers, themed monochrome, full-bleed Play icon,
  splash). To change the icon, replace that file and run `node scripts/branding/render.mjs`.
- **Text:** `scripts/branding/copy.mjs`. **Brand colours:** `BRAND` in the render script
  (cream `#F2EFE8`, ink `#14171F`, orange `#FF6A3D`).

| Play Console field | File | Spec (Play requirement) |
|---|---|---|
| App icon | `icon-512.png` | 512×512 PNG, ≤ 1 MB. Play applies the rounded mask itself |
| Feature graphic (vi) | `vi/feature-graphic.jpg` | 1024×500 JPEG, no alpha |
| Feature graphic (en) | `en/feature-graphic.jpg` | 1024×500 JPEG, no alpha |
| Phone screenshots (vi) | `vi/phone/01…05-*.jpg` | 1080×1920 (9:16) JPEG; Play needs 2–8 |
| Phone screenshots (en) | `en/phone/01…05-*.jpg` | 1080×1920 (9:16) JPEG |

Upload the `vi` set under **Vietnamese – vi-VN** and the `en` set under **English (United States) – en-US**
(Main store listing → Manage translations).

## Screenshot sources
`assets/branding/screenshots/raw/1…5.png` are 1440×3120 captures from a **release build** on a Pixel 7 Pro
emulator (demo status bar 9:41), with sample documents. Raw captures cannot be uploaded directly:
their 2.17:1 ratio exceeds Play's 2:1 limit, so they are framed into 9:16.

To refresh: capture new raw PNGs (same numbering), then `node scripts/branding/render.mjs store`.

## Not included (optional in Play Console)
- 7" and 10" tablet screenshots (needed only to appear in tablet-optimised listings).
- Promo video.
